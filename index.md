# StudentTracker

StudentTracker is an **internal tool of {{ site.org_name }}**. Our admissions staff use it on their own
Windows computers to measure how long each step of the admissions process takes for each
applicant. It is not offered to the public.

## Using StudentTracker

StudentTracker is a desktop app, not a website. To use it:

1. Open **StudentTracker** on your Windows computer. It runs in the system tray, next to the clock.
2. Right-click its icon to see the menu.

To connect or reconnect QuickBooks, see [Connect or reconnect QuickBooks](connect).
